# 구매목록 전달

장바구니 도구 줄은 정렬 → 구매완료 종수/전체 종수·수량 → 목록 전달 순서로 한 줄에 표시한다. 빈 목록에서는 전달 버튼을 비활성화한다.

- DB 링크: 현재 목록의 slug/수량을 D1 shopping_shares에 저장한다. 256비트 임의 토큰을 가진 사람만 조회할 수 있으며 한국 시간 기준 생성일의 다음 날23:59:00에 만료한다. 계정이나 실시간 공동 편집은 없고 발송 시점의 복사본이다. 수신자는 먼저 전체 목록을 확인한 뒤 가져오기를 누른다. 같은 상품은 큰 수량을 유지하며 반복 가져오기에 수량이 누적되지 않는다. 가격/상품 정보는 수신 당시 상품 DB를 사용한다.
- 이미지: 빈 체크 칸/상품명/수량/행 금액/총합을 PNG로 만든다. 한 장당 최대20종, 긴 상품명 줄바꿈. 개인정보와 상품 이미지 로딩에 의존하지 않는다. 이미지 파일 공유 미지원 환경은 다운로드를 제공한다.
- 텍스트: 같은 정렬 목록을 수량별 금액과 함께 전달한다. 기본 공유 창, 클립보드, 직접 선택 복사 순서로 대체한다.

생성 API는 동일 출처 JSON 요청만 허용하며 스트리밍 본문250KB,2500종,수량1–99,중복 slug를 검증한다. IP의 일별 SHA-256 해시로 시간당30회 제한을 적용하고 생성 시 만료 행을 정리한다. 토큰은 목록 내용과 무관하며 DB 조회는 파라미터 바인딩, no-store로 제공한다. 원본 IP/이름/연락처는 저장하지 않는다.

검증: 전체227개 테스트 통과(직렬 실행; 기존 테스트 중 빌드 결과 재생성이 있어 병렬 실행은 정적 파일 검사와 경합). 링크 저장/조회/만료/잘못된 입력/타 출처/요청 제한/반복 가져오기/텍스트 합계/도구 줄 순서 검증. 상품 DB 및 월별 할인 데이터 변경 없음.

전달 데이터에서 checked 상태를 제거한다. 이전 공유 링크도 응답 시 상태를 제거하며 새로 가져온 상품은 미구매 상태로 시작한다. 기존 수신자 장바구니에 있는 상품의 상태는 변경하지 않는다. 이미지 너비720px, 상품명34px, 수량/금액32px로 확대하고 동일 행의 별도 열에 배치한다. 긴 이름은 생략 없이 상품명 열 내 줄바꿈한다. 텍스트 각 행은 ☐ 빈 체크박스로 시작하고 마지막 줄에 PX 가이드 홈페이지 링크를 포함한다. 이미지 전체 수량/합계는 금액 열 오른쪽 끝에 정렬한다. 장바구니 도구 줄 세 요소는 삭제 버튼과 같은 .75rem, 굵기700으로 통일한다.

전달 방식 선택3개는 생성된 정사각 이미지 버튼(목록 링크/이미지/텍스트(카톡 등))이다. built-in image_gen으로 파란색/청록/네이비 배경에 연결/사진/말풍선 아이콘과 큰 흰색 한글을 각각 생성했다. 원본 assets/shopping-share/originals, 공개 자산은192/384px WebP만 사용한다. 버튼의 native 클릭/비활성화/키보드 포커스/aria-label과 기존mode 분기를 유지한다. 이미지 파일은 팝업 초기화 시 장바구니에서만 요청된다.


## 공유 목록 파일 이름과 보관 기한 (2026-10-26)

매 생성 요청은 새256비트 ID로 별도 D1 snapshot을 INSERT한다. 같은 내용이어도 기존 행을 재사용/덮어쓰지 않는다. JSON 파일명은 PX_구매목록_<한국생성시각+밀리초>_<전체ID>.json이며, DB 기본키의 유일성을 그대로 파일명에 반영한다. 이름과 정확한 한국 시간 만료시각을 생성 화면에 표시하고 같은 JSON을 파일로 내려받을 수 있다. 이름은 저장 ID/시각으로 결정적으로 구성해 중복 데이터를 추가하지 않는다.

다음날23:59:00 KST부터 GET/다운로드는404로 차단한다. 기존30일 정책 파일에도 새기한을 적용한다. 예:10월26일 생성 →10월27일23:59 KST. 이미 만료된 파일은 새 생성 시에도 정리된다.

무인 정리 호출: GET 또는 POST https://pxguide.zeromorow.chatgpt.site/api/shopping-shares/maintenance . 사용자 파일/ID를 인자로 받지 않고 오직 서버 현재시각을 기준으로 만료된 shopping_shares만 삭제한다. 먼저 오래된30일 기한을 새 정책으로 줄이고 DELETE WHERE expires_at<=now를 실행한다. 공개 호출이지만 유효한 파일을 삭제하거나 원본 상품DB를 변경할 수 없다. 반환은 deleted,remainingExpired,checkedAt 요약뿐이며 개인정보/목록/토큰을 반환하지 않는다. no-store/noindex 응답이다.

매일23:59 Asia/Seoul의 Sites 연동 클라우드 작업이 위 주소를 실제로 조회해 무인 정리를 수행한다. 조회에 현재시각의 run 쿼리를 붙여 캐시 재사용을 피한다. 정상 응답200 및 remainingExpired=0을 확인하고 오류일 때만 실패를 보고한다. 배포 후 이 공개 호출 경로를 통해 정리 작업과 결과를 직접 검증한 뒤 예약을 연결한다. 예약 실행이 지연되더라도 만료시각 이후 읽기는 즉시 차단된다.
