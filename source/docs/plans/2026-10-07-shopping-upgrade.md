# PX 장보기 기능 개선 계획

## 목표

기존 제품 320개의 품목별 탐색과 찜 기능을 유지하면서, 방문 전 실제 장보기 준비에 쓸 수 있는 목록으로 확장한다. 상품 정보와 상세 페이지에는 외부 비교 서비스의 이름, 연결 주소, 출처 문구를 노출하지 않는다. 가격의 기록 시점과 구성 불일치 가능성은 명확히 남긴다.

## 현재 기능과 개선 범위

| 확인한 기능 | 현재 상태 | 이번 변경 |
| --- | --- | --- |
| 검색과 품목 분류 | 상품명 검색, 품목 탭 | 이름·브랜드 초성 검색, 동일 구성 비교 가능 필터 |
| 가격 정렬과 비교 | PX가·일반가, 가격·할인율 정렬 | 구성 확인이 필요한 상품은 절감률에서 제외하고 결과에서 별도 표시 |
| 찜과 장보기 | 브라우저 찜, 단일 수량 합계 | 수량 조절, 구매 체크, 남은 수량과 예상 합계 |
| 목록 이동 | 같은 브라우저에만 저장 | 공유 링크 복사, 링크로 목록 가져오기(기존 목록 병합) |
| 가격 표시 | 외부 비교 서비스의 기록과 상세 링크가 노출 | 모든 상품 화면에서 서비스명·링크·출처 단락 제거, 과거 가격은 날짜와 변동 안내 유지 |

## 구현 순서

1. 상품 데이터의 외부 서비스 관련 필드와 문구를 정리하고, 여섯 상품의 공개 주소를 중립적인 주소로 바꾼다. 기존 찜 주소는 브라우저 내에서 새 주소로 이전하고, 기존 상세 주소는 새 주소로 리디렉션한다.
2. 제품 목록의 검색을 한글 초성과 브랜드까지 확장하고, 비교 가능한 구성만 보는 필터를 추가한다. 정렬·페이지네이션·품목 탭과 함께 작동하도록 한다.
3. 찜 목록에 수량, 구매 완료 체크, 남은 금액을 추가한다. 입력 상태는 브라우저에 저장하고 다른 탭 변경을 동기화한다.
4. 공유 링크는 상품과 수량만 담고, 가져올 때 기존 찜 목록에 병합한다. 너무 큰 링크나 알 수 없는 상품은 거부·무시하고 안내한다.
5. 생성된 모든 상품 페이지와 실제 배포 화면에서 외부 서비스 문자열·링크가 없는지, 찜·검색·공유 동작이 작동하는지 확인한다.

## 제한과 검증 기준

- 가격은 현재가로 표현하지 않는다. 각 상품의 기록 날짜가 있으면 표시하고, 비교 구성의 확인 여부를 함께 밝힌다.
- 장보기 합계는 등록된 PX가를 수량으로 계산한 예상치이며 현장 가격·재고와 다를 수 있다.
- 공유 링크에 방문 기록이나 계정 정보는 포함하지 않는다. 최대 60개 상품과 상품당 99개로 제한한다.
- 빌드 후 HTML, 데이터 JSON, 검색과 장보기 로직의 핵심 상태를 검증하고 기존 제품 화면의 구조를 유지한다.
