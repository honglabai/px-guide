사이트 소개

PX 구매 전에 확인할 질문과 비교 방법을 독립적으로 정리합니다.

운영 범위

이 사이트는 PX 운영기관과 제휴하지 않은 독립 안내 사이트입니다. 매장의 재고·가격·이용 자격을 실시간으로 조회하지 않습니다. 확인되지 않은 월별 할인은 게시하지 않습니다.

자료와 판단을 구분합니다

운영기관 공지와 제조사 상품 표시에서 확인한 내용은 문서 안에 출처와 적용 범위를 적습니다. 단위가격 계산과 장바구니 예시는 자체 설명으로 표시하며 실제 판매가격으로 제시하지 않습니다. 직접 써보지 않은 상품을 사용 후기나 효과 검증으로 소개하지 않습니다.

날짜와 수정

글에 보이는 수정일은 해당 원고를 실제로 고친 날짜입니다. 게시일이나 외부 자료의 확인일을 알 수 없으면 임의로 만들지 않습니다. 출처의 내용이 바뀌거나 오류가 확인되면 본문과 확인 범위를 고치고 수정일을 갱신합니다.

오류 제보와 이미지

문의 페이지로 글 주소, 수정할 문장, 근거 링크를 보내 주세요. 확인 후 정정합니다. 외부 상품 이미지는 상품 식별에 사용하지만 이미지 제공 브랜드가 이 사이트를 승인하거나 제휴했다는 뜻은 아닙니다.

광고와 독립성

현재 광고는 설정되어 있지 않습니다. 향후 광고가 게재되면 안내 콘텐츠와 구분해 표시하겠습니다.
